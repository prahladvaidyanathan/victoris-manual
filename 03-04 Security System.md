# Security System
The security system is armed after you close and lock all doors (including the engine hood and tailgate) using the keyless push start system remote controller or request switch.

Once armed, any attempt to open a door by means other than the remote controller or request switch — including using the key, the lock knob on a door, the central door locking switch, or the tailgate unlatch switch — will trigger the alarm. Opening the engine hood will also trigger the alarm.

If the shock sensor (if equipped) is enabled and its sensitivity is set above 0, the alarm will also be triggered by any attempt to tamper with the vehicle.

> **NOTE:**
> - The security system generates alarms when any of the predetermined conditions are met, but it does not block unauthorised entry into the vehicle.
> - Always use the keyless push start system remote controller or request switch to unlock the doors when the security system is armed. Using the key instead will trigger the alarm.
> - If a person who does not know the security system is going to drive the vehicle, explain the system and its operation to them. Mistakenly triggering the alarm may cause a nuisance to others.
> - Even if the security system is armed, do not leave money or valuables in the vehicle.
> - The security system is not armed when all doors are locked using the key from outside, the door lock knobs, or the central door locking switch from inside.
> - If any door is not operated within approximately 30 seconds after the doors have been unlocked using the remote controller or request switch, the doors automatically lock again and the security system will be re-armed.
> - If the security system indicator blinks when the ignition mode is ON, there may be something wrong with the security system. Ask your Maruti Suzuki authorised workshop to inspect it.
## How to Arm the Security System
Lock all doors (including the engine hood and tailgate) using the keyless push start system remote controller or request switch. When the system is armed, the security system indicator continues to blink at intervals of approximately 2 seconds.

> **NOTE:** To prevent the alarm from being accidentally triggered, avoid arming the system while anyone remains inside the vehicle. The alarm will be triggered if a person inside opens any door, tailgate, or the engine hood.
## How to Disarm the Security System
Unlock the doors using the keyless push start system remote controller or request switch. The security system indicator will go out, indicating the system is disarmed.
## How to Stop the Alarm
Should the alarm be triggered accidentally, stop it by either of the following:
- Press the engine switch or power switch to change the ignition mode to ON.
- Unlock the doors using the keyless push start system remote controller or request switch.

> **NOTE:**
> - Even after the alarm has stopped, if you lock the doors using the remote controller or request switch, the security system will be re-armed.
> - If you disconnect the battery while the security system is armed or the alarm is in operation, the alarm will be re-triggered when the battery is reconnected.
> - Even after the alarm stops at the end of the predetermined operation time, it will be triggered again if any door, tailgate, or engine hood is opened without first disarming the system.
## Checking Whether the Alarm Was Triggered During Parking
If the alarm was triggered while you were away, when you change the ignition mode to ON the security system indicator will blink rapidly for about 8 seconds and a buzzer will beep 4 times. If this happens, check whether the vehicle has been broken into.
## Security System Indication
- If any door or the tailgate is opened without unlocking using the remote controller or request switch, all turn signal lights start to blink and the interior buzzer beeps intermittently. After 5 seconds, the siren sounds for about 27.5 seconds. The security system indicator continues to blink during this time.
- If the engine hood is opened, all turn signal lights blink and the siren sounds for about 27.5 seconds. The security system indicator continues to blink during this time.

**(If shock sensor is equipped and enabled)**
- If the vehicle feels a shock above the pre-warning sensitivity level, the siren sounds for about 2 seconds (pre-warning).
- If the vehicle feels a shock above the full blast warning sensitivity level, the siren sounds for about 5 seconds (full blast warning).
- If the full blast warning sensitivity is set higher than the pre-warning sensitivity, or the shock is strong enough to trigger the full blast warning, the full blast warning triggers directly without a pre-warning.

The security system indicator continues to blink throughout any alarm event.
## Shock Sensor Settings (if equipped)
The shock sensor is disabled by default. To enable it and adjust the sensitivity of the pre-warning and full blast warning functions, use the setting mode of the information display or ask your Maruti Suzuki authorised workshop.
