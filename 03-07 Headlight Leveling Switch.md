# Headlight Leveling Switch
Level the headlight beam according to the load condition of your vehicle by turning this switch. Your car is fitted with LED headlights. Use the switch positions below:

| Vehicle Load Condition | Switch Position |
|---|---|
| Driver only | 0 |
| Driver + 1 passenger (front seat) | 0 |
| Driver + 4 passengers, no cargo | 1 |
| Driver + 4 passengers, cargo added | 2.0 |
| Driver + full cargo | 3.5 |
