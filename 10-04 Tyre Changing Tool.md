# Tyre Changing Tool
## Tools Provided
The following tyre changing tools are supplied with the vehicle:

| Label | Tool |
|-------|------|
| (1) | Jack |
| (2) | Jack handle |
| (3) | Wheel wrench |
| (4) | Towing eye |

## Location
The tyre changing tools are stowed in the luggage compartment, below the luggage compartment boards.

Before using the jack, check that it has no deformation or damage, that the screw part is clean, and that grease is applied to it.

## Removing the Jack
1. Remove the luggage compartment board by lifting it using the strap.
2. Remove the jack.

> **WARNING:** After using the tyre changing tools, be sure to stow them securely — unsecured tools can cause injury in an accident.
